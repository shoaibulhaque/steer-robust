# Maintaining Steer Robust

This repository authors the reusable baseline under `src/`; do not install it globally while editing.
Preserve project/user authority and the legitimate exceptions in each engineering rule.
Do not delegate without the user's explicit approval.
Keep instructions concise and progressively disclosed; follow the instruction word budgets.
Judge code by justified design, guarantees and reader load, not arbitrary line/function/test limits.
Use the checks in [CONTRIBUTING.md](CONTRIBUTING.md) after relevant changes.
Keep skill metadata narrow and resource links portable; shared policy has one owner.
Never publish credentials, personal paths, private task evidence or research checkouts.
